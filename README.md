# 🛒 Amazon Clone

A responsive, static front-end clone of the Amazon e-commerce platform built to demonstrate pixel-accurate layout design, DOM manipulation, and smooth user interactions using vanilla HTML, CSS, and JavaScript.

## ✨ Features

- **Responsive Layout:** Tailored navigation header, banner slider, and product grid optimized for desktop and mobile viewports.
- **Categorized Shopping Section:** Structured grid layouts displaying varied product lines and deals.
- **Interactive UI Elements:** Dynamic navigation elements, hover effects, and back-to-top scrolling mechanics.
- **Clean UI Structure:** High-fidelity replication of Amazon's design language, color scheme, and typography.

⚙️ Getting Started
To run this project locally on your machine:
 * Clone the repository:
   git clone [https://github.com/ZAIN1490/Amazon-clone.git](https://github.com/ZAIN1490/Amazon-clone.git)

 * Navigate to the project directory:
   cd Amazon-clone

 * Open the project:
   Simply double-click index.html or open it using VS Code's Live Server extension.
